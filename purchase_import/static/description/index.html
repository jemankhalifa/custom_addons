Purchase Lines Import

The Purchase Lines Import module by Net4X Innovation enhances the Odoo Purchase app by allowing users to import bulk product lines directly into Purchase Orders using Excel files.

Key Features:

  • Bulk import of product lines into Purchase Orders via Excel.
  • Auto-create purchase orders by selecting vendor, order type, and date.
  • Streamlined process with form and tree view integration.
  • Interactive wizard for uploading and processing files.
  • Supports standard Odoo workflows with secure access rights.

How It Works:

  1. Go to Purchases > Import Order Lines.
  2. Open the import wizard.
  3. Select the order date, supplier, order type, and upload your Excel file.
  4. Click Create Order to instantly generate the Purchase Order.

Dependencies:

  • purchase
  • account

Installation:

  1. Copy the module into your Odoo addons/ directory.
  2. Update the Apps list from the Odoo backend.
  3. Search for Purchase Lines Import and install it.
